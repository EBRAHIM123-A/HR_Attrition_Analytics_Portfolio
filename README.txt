HR EMPLOYEE ATTRITION ANALYTICS
Employee Attrition Analysis & HR Insights
============================================================

Start here: Documentation/README.md

This project analyzes the public IBM HR Employee Attrition & Performance dataset
(1,470 employees) end to end:

  Raw Data -> Cleaning -> Power Query -> EDA -> Data Mining -> SQL -> Power BI -> Insights -> Recommendations

Folders:
  Excel/          One workbook, 12 sheets, real data and formulas
  Power_BI/       DAX measures, data model, dashboard design, theme
  Power_Query/    Cleaning steps as Power Query M code
  Python/         Runnable EDA and data mining scripts
  SQL/            Schema + 5 query files matching the same analysis
  Documentation/  Full write-up, including an interview-prep Q&A

Key number: overall attrition rate = 16.12% (237 of 1,470 employees).
Every other number in this project is documented and traceable back to this same dataset.
